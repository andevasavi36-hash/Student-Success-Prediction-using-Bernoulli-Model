# Student-Success-Prediction-using-Bernoulli-Model
It is the process of using data and statistical or machine learning models (like Bernoulli models) to predict whether a student will pass or fail based on features such as attendance, study hours, and exam scores.
This project focuses on predicting student success (pass/fail) using a probabilistic machine learning approach based on the Bernoulli distribution. The model treats student outcomes as binary variables and estimates the probability of success using key academic and behavioral features.

🎯 Objective

To develop a predictive model that helps identify students who are likely to succeed or struggle academically, enabling early intervention and improved learning outcomes.

📊 Methodology
Data preprocessing and cleaning
Feature selection (attendance, study hours, previous performance, etc.)
Application of Bernoulli Naive Bayes / Bernoulli probability model
Model evaluation using accuracy, precision, and recall
🧠 Key Concepts
Bernoulli Distribution
Binary Classification
Probability-based prediction
Machine Learning fundamentals
🛠️ Technologies Used
Python
Pandas & NumPy
Scikit-learn
Jupyter Notebook
📈 Results

The model predicts whether a student will succeed (1) or fail (0) based on input features with measurable accuracy.
